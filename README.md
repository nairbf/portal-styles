# portal-styles

Custom stylesheet for the Signature DJ Events client portal (DJ Event Planner).

- `portal.css` — the full portal stylesheet: the original DJEP stylesheet with a
  Signature DJ Events skin appended at the bottom.

Served at: https://nairbf.github.io/portal-styles/portal.css

To adjust the look, edit the override layer at the bottom of `portal.css`
(everything after the "SIGNATURE DJ EVENTS — CLIENT PORTAL SKIN" banner).
Deleting from that banner to the end of the file restores the original design.
